# NetHack風ローグライクゲーム - Pythonで作った炭治郎の冒険

Pythonで作られたNetHackスタイルのローグライクゲームです。2つのバージョンがあります！

## 🎮 ゲームバージョン

### 1. **Pygame版**（グラフィカル・推奨）
カスタムスプライト対応のグラフィカル版

👉 **[Pygame版の詳細はこちら](README_PYGAME.md)**

**特徴:**
- 炭治郎のドット絵を主人公として使用可能
- グラフィカルな表示
- スムーズな操作感
- カスタマイズ可能

**起動方法:**
```bash
pip install pygame
python3 roguelike_pygame.py
```

### 2. **curses版**（ターミナル版）
クラシックなASCIIベースのローグライク

👉 **[curses版の詳細はこちら](README_ROGUELIKE.md)**

**特徴:**
- クラシックなローグライクの雰囲気
- ターミナルで動作
- 軽量で高速

**起動方法:**
```bash
python3 roguelike_game.py
```

## 🎯 ゲームの特徴

### 共通機能
- ✅ 5階層のランダム生成ダンジョン
- ✅ ペットシステム（犬または猫）
- ✅ ターンベースの戦闘
- ✅ レベルアップシステム
- ✅ 複数種類の敵（ゴブリン、オーク、トロール、ドラゴン）
- ✅ アイテムシステム
- ✅ NetHack風の墓石表示

## 🚀 クイックスタート

### Pygame版（推奨）

```bash
# 1. Pygameをインストール
pip install pygame

# 2. 炭治郎の画像を配置（オプション）
# tanjiro.png を同じディレクトリに配置

# 3. ゲーム起動
python3 roguelike_pygame.py
```

### curses版

```bash
# そのまま起動できます
python3 roguelike_game.py
```

## 🎮 操作方法

### 共通操作
- **矢印キー** または **WASD**: 移動
- **>**: 下の階に移動
- **<**: 上の階に移動
- **i**: インベントリ表示
- **q**: 終了

## 🎨 スプライトのカスタマイズ

Pygame版では炭治郎のドット絵を使用できます：

1. 32x32ピクセルのPNG画像を用意
2. ファイル名を `tanjiro.png` に変更
3. ゲームと同じディレクトリに配置

画像がない場合は自動的にプレースホルダーが使用されます。

## 📊 ゲーム統計

- **階層**: 5階層のダンジョン
- **敵の種類**: 4種類（ゴブリン、オーク、トロール、ドラゴン）
- **ペット**: 2種類（犬、猫）
- **アイテム**: 回復ポーション、宝物

## 🎯 ゲームの目標

1. ゲーム開始時にペットを選択（犬または猫）
2. 5階層のダンジョンを探索
3. 最下層（5階）の宝物を見つける
4. ペットと協力して生き延びる

## 💡 攻略のヒント

1. **ペットを守る**: ペットは復活しません
2. **階層を戻る**: 危険な時は上の階で回復
3. **レベルアップ**: 各階で十分に敵を倒してから次へ
4. **協力戦闘**: ペットと挟み撃ちで有利に

## 🔧 必要な環境

- Python 3.6以上
- **Pygame版**: `pygame` パッケージ
- **curses版**: Linux/Mac（標準）、Windows（`windows-curses`が必要）
