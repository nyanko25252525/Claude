# グラフィカル版ローグライクゲーム - 炭治郎の冒険

Pygameを使用したグラフィカル版のNetHackスタイル・ローグライクゲームです！

## 🎮 特徴

- **グラフィカルな表示**: cursesの代わりにPygameを使用
- **カスタムスプライト**: 炭治郎のドット絵を主人公として使用可能
- **スムーズな操作**: マウスとキーボードでの快適な操作
- **全ての元の機能**: 5階層ダンジョン、ペットシステム、戦闘、レベルアップなど

## 🔧 必要なもの

- Python 3.6以上
- Pygame 2.0以上

### インストール

```bash
# Pygameのインストール
pip install pygame

# または
pip3 install pygame
```

## 🖼️ 炭治郎スプライトの設定

### 方法1: 画像を配置する（推奨）

1. 炭治郎のドット絵画像（PNG形式）を用意
2. ファイル名を `tanjiro.png` に変更
3. このREADMEと同じディレクトリに配置

```
/home/user/Claude/
├── roguelike_pygame.py
├── tanjiro.png          ← ここに配置！
└── README_PYGAME.md
```

**画像の推奨サイズ**: 32x32ピクセル（自動的にリサイズされます）

### 方法2: サンプルスプライトを使用

画像がない場合、ゲームは自動的に黄色のプレースホルダー（@マーク）を使用します。

## 🎯 遊び方

### ゲームの起動

```bash
python3 roguelike_pygame.py
```

または

```bash
chmod +x roguelike_pygame.py
./roguelike_pygame.py
```

### 操作方法

#### 移動
- **矢印キー** または **WASD**: 上下左右に移動

#### 階段
- **Shift + >** (Shift + ピリオド): 下の階に移動
- **Shift + <** (Shift + カンマ): 上の階に移動

#### その他
- **I キー**: インベントリを表示
- **Q キー** または **ESC キー**: ゲームを終了

### ゲームの流れ

1. **ペット選択**
   - ゲーム開始時に犬または猫を選択
   - 1キーで犬、2キーで猫

2. **ダンジョン探索**
   - 炭治郎（@マーク）を操作
   - 5階層のダンジョンを探索
   - 最下層の宝物を目指す

3. **戦闘**
   - 敵に隣接して移動すると自動攻撃
   - ペットも自動的に戦闘をサポート

## 🎨 ビジュアル要素

### キャラクター表示

| 要素 | 表示 | 説明 |
|------|------|------|
| プレイヤー | 炭治郎スプライト（または黄色の@） | あなたが操作するキャラクター |
| ペット | 青い円 | 犬または猫の仲間 |
| 敵 | 赤い円 | ゴブリン、オーク、トロール、ドラゴン |
| 回復ポーション | 緑の円 | HPを回復 |
| 宝物 | シアンの円 | ゲームクリアアイテム |
| 下り階段 | マゼンタの > | 次の階へ |
| 上り階段 | マゼンタの < | 前の階へ |
| 壁 | 濃い灰色 | 通過不可 |
| 床 | 灰色 | 移動可能 |

### UI表示

画面下部に以下の情報が表示されます：

- **プレイヤー情報**: HP、レベル、経験値、攻撃力、防御力
- **ペット情報**: HP、現在のフロア
- **メッセージログ**: 最新3件のゲームイベント

## 🎮 ゲームシステム

### ペットシステム
- **犬**: HP 30, ATK 8 - より強力で耐久力あり
- **猫**: HP 20, ATK 6 - 機敏で扱いやすい

### 複数フロアダンジョン
- 全5階層
- 深い階ほど敵が強くなる
- 宝物は5階のみに出現

### 戦闘とレベルアップ
- 敵を倒すと経験値獲得
- レベルアップでステータス強化
- ペットも自動的に戦闘参加

## 🔄 cursesバージョンとの違い

| 項目 | curses版 | Pygame版 |
|------|----------|----------|
| 表示 | テキストベース | グラフィカル |
| プレイヤー | @マーク | カスタム画像対応 |
| 敵・アイテム | 文字 | 色付き図形 |
| 操作感 | ターミナル依存 | スムーズ |
| カスタマイズ | 難しい | 画像差し替え可能 |

## 💡 カスタマイズのヒント

### 他のキャラクターも画像にしたい場合

`roguelike_pygame.py` を編集して、以下の部分で画像を読み込むことができます：

```python
# 敵の画像を読み込む例
goblin_sprite = pygame.image.load('goblin.png')
orc_sprite = pygame.image.load('orc.png')

# 描画時に使用
self.screen.blit(goblin_sprite, (x, y))
```

### タイルサイズを変更したい場合

```python
# roguelike_pygame.py の最初の方
TILE_SIZE = 32  # この値を変更（例: 48, 64など）
```

## 🐛 トラブルシューティング

### Q: ゲームが起動しない
A: Pygameがインストールされているか確認してください
```bash
python3 -c "import pygame; print(pygame.version.ver)"
```

### Q: 画像が表示されない
A: 以下を確認してください：
- `tanjiro.png` が正しいディレクトリにあるか
- ファイル名が正確か（大文字小文字も区別されます）
- 画像ファイルが破損していないか

### Q: 動作が重い
A: タイルサイズを小さくするか、FPSを下げてください
```python
FPS = 30  # 60から30に変更
```
