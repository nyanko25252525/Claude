# シンプルなローグライクゲーム

NetHackにインスパイアされた、Pythonで作られたシンプルなローグライクゲームです。

## 特徴

- **ランダム生成されるダンジョン**: 毎回異なるマップで遊べます
- **ターンベースの戦闘**: 戦略的に敵と戦いましょう
- **レベルアップシステム**: 経験値を得て強くなります
- **様々な敵**: ゴブリン、オーク、トロール、ドラゴンなど
- **アイテム**: 回復ポーションで体力を回復
- **ASCIIグラフィック**: クラシックなローグライクの雰囲気
- **NetHack風の墓石**: 死亡時にRIP（Rest In Peace）と書かれた墓石を表示

## 必要なもの

- Python 3.6以上
- cursesライブラリ（Linuxでは標準、Windowsでは`windows-curses`が必要）

### Windowsの場合

```bash
pip install windows-curses
```

## 遊び方

### ゲームの開始

```bash
python roguelike_game.py
```

または

```bash
chmod +x roguelike_game.py
./roguelike_game.py
```

### 操作方法

- **移動**: 矢印キーまたは WASD
  - ↑ / W: 上に移動
  - ↓ / S: 下に移動
  - ← / A: 左に移動
  - → / D: 右に移動
- **i**: インベントリを表示
- **q**: ゲームを終了

### ゲームの目標

ダンジョンを探索し、敵を倒しながら**宝物（$）**を見つけましょう！

### シンボルの意味

- `@` - プレイヤー（あなた）
- `g` - ゴブリン（弱い敵）
- `o` - オーク（中程度の敵）
- `T` - トロール（強い敵）
- `D` - ドラゴン（非常に強い敵）
- `!` - 回復ポーション
- `$` - 宝物（ゲームクリアアイテム）
- `.` - 床（移動可能）
- `#` - 壁（移動不可）

## ゲームシステム

### 戦闘

敵のいるマスに移動すると自動的に攻撃します。
- ダメージは攻撃力からランダムに計算されます
- 防御力でダメージを軽減できます
- 敵を倒すと経験値を獲得します

### レベルアップ

経験値が一定値に達するとレベルアップします：
- 最大HPが増加
- HPが全回復
- 攻撃力が上昇
- 防御力が上昇

### 敵のAI

敵はプレイヤーが近くにいると追いかけてきます：
- 視界範囲: 6マス
- 隣接すると攻撃してきます

### アイテム

- **回復ポーション**: 拾うと自動的に使用され、HPを20回復します

### ゲームオーバー

プレイヤーが死亡すると、NetHack風の墓石が表示されます：
- **RIP（Rest In Peace）**と刻まれた墓石のASCIIアート
- 到達したレベル
- 死因（倒された敵の名前）
- 倒した敵の数
- 生存ターン数

これらの統計情報を見て、次回のプレイでより良い成績を目指しましょう！

## ゲームのヒント

1. **慎重に進む**: 複数の敵に囲まれないように注意
2. **レベルアップを狙う**: 弱い敵から倒して経験値を稼ぐ
3. **HPに注意**: HPが少なくなったら回復ポーションを探す
4. **部屋を活用**: 廊下で戦うと一度に一体ずつ相手にできます
5. **ドラゴンに注意**: 非常に強いので、レベルが低いうちは避けましょう

## 技術詳細

### アーキテクチャ

- **Entity**: プレイヤーと敵の基底クラス
- **Dungeon**: ランダムなダンジョン生成を担当
- **Game**: ゲームループとロジックを管理
- **curses**: ターミナルUIライブラリ

### ダンジョン生成アルゴリズム

1. ランダムな位置に部屋を生成（5〜8個）
2. 重なりをチェック
3. 隣接する部屋をL字型の廊下で接続
