# シンプルなローグライクゲーム

NetHackにインスパイアされた、Pythonで作られたシンプルなローグライクゲームです。

**🎮 NEW! [グラフィカル版（Pygame）はこちら](README_PYGAME.md)**

## 特徴

- **ランダム生成されるダンジョン**: 毎回異なるマップで遊べます
- **複数フロアのダンジョン**: 5階層のダンジョンを探索
- **ペットシステム**: 犬または猫を相棒に選んで一緒に冒険
- **ターンベースの戦闘**: 戦略的に敵と戦いましょう
- **レベルアップシステム**: 経験値を得て強くなります
- **様々な敵**: ゴブリン、オーク、トロール、ドラゴンなど
- **アイテム**: 回復ポーションで体力を回復
- **ASCIIグラフィック**: クラシックなローグライクの雰囲気
- **NetHack風の墓石**: 死亡時にRIP（Rest In Peace）と書かれた墓石を表示

## 必要なもの

- Python 3.6以上
- cursesライブラリ（Linuxでは標準、Windowsでは`windows-curses`が必要）

### Windowsの場合

```bash
pip install windows-curses
```

## 遊び方

### ゲームの開始

```bash
python roguelike_game.py
```

または

```bash
chmod +x roguelike_game.py
./roguelike_game.py
```

### 操作方法

- **移動**: 矢印キーまたは WASD
  - ↑ / W: 上に移動
  - ↓ / S: 下に移動
  - ← / A: 左に移動
  - → / D: 右に移動
- **>**: 下の階に移動（下り階段の上で実行）
- **<**: 上の階に移動（上り階段の上で実行）
- **i**: インベントリを表示
- **q**: ゲームを終了

### ゲームの目標

1. ゲーム開始時に**ペット（犬または猫）**を選択
2. 5階層のダンジョンを探索
3. 最下層（5階）にある**宝物（$）**を見つける
4. ペットと協力して敵を倒しながら生き延びる

### シンボルの意味

#### キャラクター
- `@` - プレイヤー（あなた）
- `d` - 犬（ペット）- HP: 30, ATK: 8
- `f` - 猫（ペット）- HP: 20, ATK: 6

#### 敵
- `g` - ゴブリン（弱い敵）
- `o` - オーク（中程度の敵）
- `T` - トロール（強い敵）
- `D` - ドラゴン（非常に強い敵）

#### アイテム・地形
- `!` - 回復ポーション
- `$` - 宝物（ゲームクリアアイテム、5階のみ）
- `>` - 下り階段
- `<` - 上り階段
- `.` - 床（移動可能）
- `#` - 壁（移動不可）

## ゲームシステム

### ペットシステム

ゲーム開始時にペットを選択します：
- **犬**: より強力（HP: 30, ATK: 8, DEF: 1）
- **猫**: より機敏（HP: 20, ATK: 6, DEF: 0）

ペットの特徴：
- プレイヤーに自動的に追従します
- 近くの敵を自動的に攻撃します
- ペットが倒した敵も経験値とキルカウントに加算されます
- ペットが死ぬと復活しません（大切に！）

### 複数フロアシステム

ダンジョンは5階層あります：
- 各階には下り階段（`>`）と上り階段（`<`）があります
- 階段の上で`>`または`<`キーを押すとフロア移動
- 深い階ほど敵が強く、数も多くなります
- **宝物は5階（最下層）にのみ出現します**

階層別の敵分布：
- **1階**: ゴブリン中心
- **2階**: ゴブリンとオーク
- **3階**: オークとトロール
- **4階**: トロールとドラゴンが出現
- **5階**: 強敵ばかり（トロール、ドラゴン）

### 戦闘

敵のいるマスに移動すると自動的に攻撃します。
- ダメージは攻撃力からランダムに計算されます
- 防御力でダメージを軽減できます
- 敵を倒すと経験値を獲得します
- ペットも自動的に近くの敵と戦います

### レベルアップ

経験値が一定値に達するとレベルアップします：
- 最大HPが増加
- HPが全回復
- 攻撃力が上昇
- 防御力が上昇

### 敵のAI

敵はプレイヤーが近くにいると追いかけてきます：
- 視界範囲: 6マス
- 隣接すると攻撃してきます
- ペットにも攻撃します

### アイテム

- **回復ポーション**: 拾うと自動的に使用され、HPを20回復します

### ゲームオーバー

プレイヤーが死亡すると、NetHack風の墓石が表示されます：
- **RIP（Rest In Peace）**と刻まれた墓石のASCIIアート
- 到達したレベル
- 死因（倒された敵の名前）
- 倒した敵の数
- 生存ターン数

これらの統計情報を見て、次回のプレイでより良い成績を目指しましょう！

## ゲームのヒント

1. **ペット選択**:
   - 犬は耐久力があり、長期戦向き
   - 猫は攻撃力は低いが、機敏で扱いやすい
2. **階層を戻る**:
   - 危険を感じたら上の階に戻って回復アイテムを探しましょう
   - 5階に行く前に十分レベルアップすることが重要
3. **ペットを守る**:
   - ペットが死ぬと復活しません
   - ペットのHPに気を配り、危険な時は階段で逃げましょう
4. **レベルアップを狙う**:
   - 各階で敵を倒してレベルを上げてから次の階へ
   - 推奨：2階到達時レベル3、5階到達時レベル5以上
5. **協力プレイ**:
   - ペットと一緒に敵を挟み撃ちにすると効果的
   - 廊下で戦うと一度に一体ずつ相手にできます
6. **深い階の注意**:
   - 4階以降はドラゴンが出現します
   - HPが半分以下の時は無理せず上の階で回復を

## 技術詳細

### アーキテクチャ

- **Entity**: プレイヤー、敵、ペットの基底クラス
  - **Player**: プレイヤーキャラクター（経験値、レベル管理）
  - **Enemy**: 敵キャラクター（種類別のステータス）
  - **Pet**: ペット（追従AI、戦闘サポート）
- **Dungeon**: ランダムなダンジョン生成を担当
- **Game**: ゲームループ、複数フロア管理、AI制御
- **curses**: ターミナルUIライブラリ

### ダンジョン生成アルゴリズム

1. ランダムな位置に部屋を生成（5〜8個）
2. 重なりをチェック
3. 隣接する部屋をL字型の廊下で接続
4. 各フロアに階段を配置
5. 最下層（5階）にのみ宝物を配置

### ペットAI

ペットは以下のロジックで行動します：
1. 隣接する敵がいれば攻撃
2. なければプレイヤーから距離2以上離れている場合、追従
3. プレイヤーに近い場合は待機
